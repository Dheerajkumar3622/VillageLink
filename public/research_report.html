1 Introduction (Parichay)

Yeh report VillageLink project ki ek deep architectural aur functional detail hai. VillageLink ek rural super-app hai jo public transport booking, live tracking, food & mess subscriptions, aur local village logistics ko ek jagah lata hai. Is report me backend architecture, database models, frontend components, aur core functionalities ka pura detail Hindi-Hinglish mein explain kiya gaya hai.

2 Backend Architecture & APIs

Server Setup (Node.js & Express)

Pura backend Node.js pe based hai environment `server.js` ke through run hota hai. Isme Express.js framework use hua hai web routes ke liye. Security ke liye Helmet, express-rate-limit (taaki APIs ko spam/DDoS se bachaya ja sake) aur express-mongo-sanitize use kiya gaya hai.

Real-Time Engine (Socket.io)

Driver ki live tracking, chat, aur vehicle trajectory matching ke liye WebSocket / Socket.io engine kaam karta hai. Drivers apni GPS location bhejte hain jo backend mein process hoke passengers ko real-time dikhayi deti hai.

Payments Gateway (Razorpay)

Online payments receive karne ke liye backend me Razorpay API ka integration hai. Log tickets, food pass sab Razorpay, Wallet balance ya GramCoin ke zariye pay kar sakte hain.

3 Database Schema (MongoDB)

Mongoose ke zariye MongoDB models banaye gaye hain jo `backend/models.js` file mein stored hain. Yahan kaafi vast role-based access control hai.

User & Roles
  • Users ke kafi roles hain: PASSENGER, DRIVER, ADMIN, SHOPKEEPER, FOOD_VENDOR aadi.
  • Isme Wallet Balance, Hero Points, aur Credit Limit track hoti hai.
Ticketing & Passes
  • Ticket: Normal transport journey ke liye booking (cash or online).
  • Pass: Monthly/Weekly journeys ke liye route passes.
FoodLink Ecosystem
  • FoodVendor & Restaurant: Street vendors aur dhaba owners ka database.
  • FoodOrder & TableBooking: Remote ordering aur mess subscription.
Live Tracking Models
  • DriverLocation: Current GPS coords, speed, heading.
  • RoadSegment: Live traffic map ke liye segment crowdsourcing.

4 Frontend Architecture (React/Vite)

UI ka frontend React.js, Vite aur Tailwind CSS pe bana hai. Yeh capacitor (Ionic Capacitor) ke through native Android APK (`VillageLink-v3.5.apk`) mein wrap kiya gaya hai. "Whisk 3.0 / Nano Banana" design theme follow ki gayi hai jisme glassmorphism aur 3D aesthetics hain.

Major Frontend Modules:
  • UserApp.tsx: Passenger view, Reels, Chat, Gram Mandi aur Food sections tabs mein bante hue hain jisme V5BottomNav kaam karta hai.
  • DriverApp.tsx & ProviderApp.tsx: Drivers aur Shopkeepers/Vendors ke panel alag hain scan ticket, route accept karne ke liye.
  • UniversalQRScanner: Har module QR code scan karne ka capability rakhta hai, tickets auto-verify karne ke liye.

5 Core Functionalities (Workflows)

Transport & Live Tracking

User `JourneyPlanner` component se destination daalta hai. Backend OSRM routing ya DB coordinates use karke distance nikalta hai. Ticket book hone ke baad QR generate hota hai. Bus me chadhne pe Driver `UniversalQRScanner` se usko scan karke verify (BOARDED) karta hai. Poori raste bhar live map pe bus ki location `LiveTracker.tsx` ke through dikhti hai.

FoodLink & Vyapar Saathi

Street vendors aur Dhaba owners ko digital onboarding mili hai. Users `FoodLinkHome` me unko dhoond sakte hain, "Mess Subsriptions" (MessPass) kharid sakte hain. Vendors ke liye `VendorKhata` (Digital ledger) hai jo unki hisaab-kitaab maintain karta hai.

Driver Earnings & Platform Fees

Jab ticket scan hota hai, toh backend calculate karta hai ki ticket 'ONLINE' paid hai ya 'CASH'. Agar ONLINE hai, toh admin fee (10%) kaat ke driver ke wallet me amount credit hota hai (`transactionType: EARN`). Agar CASH hai, toh driver customer se seedha cash leta hai, aur 10% platform fee uske wallet balance se deduct (`SPEND`) hoti hai.

Conclusion (Nishkarsh)

VillageLink ek highly robust aur scalable app hai jisko micro-services ki tarah component architecture mein build kiya gaya hai. Iska use of WebSocket for real-time traffic, Razorpay/Wallet for transactions, aur Capacitor for multi-platform delivery isko ek true enterprise-grade Super App banata hai.
